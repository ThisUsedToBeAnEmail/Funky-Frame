Features

Funky.Clock provides real-time clock display with multiple capabilities:

  • Digital: Text-based time display with format options
  • Analog: SVG clock face with hour, minute, second hands
  • Both: Combined analog + digital display
  • Timezones: Display time in any IANA timezone
  • Countdown: Count down to a target time
  • Stopwatch: Count up with millisecond precision
  • Scheduling: Execute callbacks at specific times or intervals

Use data-clock attribute with data-style, data-format, data-timezone options.
