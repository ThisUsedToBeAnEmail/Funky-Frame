Features

The Tour component provides interactive onboarding and feature discovery:

  • Step-by-step guidance: Highlight elements with tooltips
  • Overlay support: Focus attention with backdrop dimming
  • Progress tracking: Show current step and total steps
  • Keyboard navigation: Use arrow keys, Escape to close
  • Persistence: Remember completion state across sessions
  • SPA integration: Works with Funky.Pages lifecycle

Keyboard shortcuts:

  • → / Enter - Next step
  • ← - Previous step
  • Escape - Close tour
  • Tab - Navigate within tooltip
