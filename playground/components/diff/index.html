Features

The Diff component supports multiple comparison modes:

  • Text Diff: Line-by-line comparison with word-level highlighting
  • JSON Diff: Deep object comparison with collapsible tree view
  • Audit Diff: Field-by-field comparison with custom renderers

Modes for text diff:

  • Split: Side-by-side with synchronized scrolling
  • Side-by-Side: Independent scrolling panels
  • Inline: Unified view with +/- markers

Option behaviors:

  • Toggle Collapse: Collapses consecutive unchanged lines (the validation section in the example has 10 identical lines - when enabled, these collapse to a "5 unchanged lines" button)
  • Word Diff: Shows word-level highlights on changed lines (e.g., "old" → "new", "100" → "500")
