Keyboard Navigation

ActionBar uses roving tabindex for keyboard navigation:

  • Tab - Focus the action bar (first button)
  • ← / → - Move between buttons
  • Home - Focus first button
  • End - Focus last button
  • Enter / Space - Activate button
