Navigation API

Use the navigation API to move between matches programmatically.

The Funky.Highlight module lets you navigate through matches. The navigation API cycles through each occurrence. The previous and next buttons move between matches. The goTo method jumps to a specific index. The scrollToFirst method resets to the first match.

The current match gets a distinct "current" highlight style, making it stand out from the others. The navigation wraps around - going next from the last match returns to the first, and going prev from the first goes to the last.

The count method returns the total number of matches for the UI. The hasHighlights method checks if any highlights are active. The clear method removes all highlights from the element.
