Skip Link

Accessible skip links for keyboard navigation to bypass repetitive content. Uses F-keys (F3-F12) for quick navigation.

How It Works

Keyboard Navigation:
  • Press Tab at the top of any page - a "Keyboard shortcuts" link appears and the help modal opens
  • Use F-keys (F3-F5, F7-F12) to skip directly to registered targets
  • F6 is reserved for region navigation (standard accessibility shortcut)
  • Skip targets are auto-discovered via data-skip-target attribute
