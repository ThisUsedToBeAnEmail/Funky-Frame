Live Binding

Reactive data binding that automatically updates DOM elements when data changes from events, WebSocket, cache, or API sources.

Event-Driven Binding

LiveBinding listens to events and renders data using a template. Click "Emit Event" to trigger updates.

Programmatic API

Control the binding above using the LiveBinding API methods.

Template Engine

LiveBinding includes a Mustache-style template engine with formatters and loop support.

Formatters

{{value|upper}}
Uppercase text
{{value|lower}}
Lowercase text
{{price|currency}}
Currency format
{{ratio|percent}}
Percentage format
{{date|relative}}
Relative time
{{text|truncate:20}}
Truncate with limit

Sections

{{#items}}...{{/items}}
Loop over array
{{#visible}}...{{/visible}}
Conditional (if truthy)
{{^empty}}...{{/empty}}
Inverted (if falsy)
{{@index}}
Loop index
{{@first}}
First item flag
{{{raw}}}
Unescaped HTML

Source Adapters

LiveBinding supports multiple data sources: event, cache, websocket, api, and computed.

Event

Listens to PubSub events for real-time updates.

source: 'event', event: 'my:event'

Cache

Binds to Funky.Cache, updates when cache changes.

source: 'cache', entity: 'user', property: 'name'

WebSocket

Real-time streaming from WebSocket channels.

source: 'websocket', channel: 'prices'

API

REST API with optional polling interval.

source: 'api', url: '/api/data', interval: 5000

Declarative Binding

Use data attributes to bind elements without JavaScript.

<span data-live-bind="cache:trades:count"></span>

Binds to cache entity "trades", property "count"

<div data-live-bind="websocket:prices:GBPUSD" data-live-template="£{{price|number:4}}"></div>

WebSocket channel with template

<ul data-live-bind="event:activity" data-live-append data-live-prepend data-live-max="10"></ul>

Streaming list with max items
