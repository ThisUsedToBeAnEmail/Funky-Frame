Polite Announcements

Non-interrupting announcements. The screen reader waits for a pause before reading. Best for: updates, loading states, confirmations.

Assertive Announcements

Interrupting announcements. The screen reader stops and reads immediately. Best for: errors, urgent alerts, critical information.

Best Practices

Guidelines for when to use polite vs assertive announcements.

Use Polite for:
  • Content updates (new items loaded)
  • Loading states and progress
  • Success confirmations
  • Filter/sort changes
  • Non-critical status updates
  • Search results count
Use Assertive for:
  • Error messages
  • Form validation failures
  • Session timeouts
  • Connection issues
  • Critical warnings
  • Time-sensitive alerts
