Format Examples

Common formatting use cases

Number: Funky.Format.number(1234567.89) 1,234,567.89
Compact: Funky.Format.compact(1234567) 1.23M
Currency (GBP): Funky.Format.currency(1234.56, 'GBP') £1,234.56
Currency (USD): Funky.Format.currency(1234.56, 'USD') $1,234.56
Percentage: Funky.Format.percentage(0.1234) 12.34%
Change (Positive): Funky.Format.change(5.25) +5.25%
Change (Negative): Funky.Format.change(-3.75) -3.75%
File Size: Funky.Format.fileSize(1536000) 1.46 MB
Date: Funky.Format.date('2025-01-15') 15 Jan 2025
DateTime: Funky.Format.datetime('2025-01-15T14:30:00') 15 Jan 2025, 14:30
