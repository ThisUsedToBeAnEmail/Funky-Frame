Features

    

      
The Typewriter component provides animated typing effects:

      
    
        
  • Modes: Type by letter, word, or line
    • 
        
  • Cursor Styles: Bar, underscore, block, or none
    • 
        
  • Looping: Cycle through multiple text sequences
    • 
        
  • Size Variants: xs, sm, md, lg, xl, 2xl, 3xl, 4xl
    • 
        
  • Callbacks: onStart, onType, onComplete, onLoop, onDelete
    • 
      

      
Accessibility: Respects prefers-reduced-motion - shows text instantly.
