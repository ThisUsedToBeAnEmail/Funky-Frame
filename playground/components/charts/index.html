Data Attribute Initialization

Initialize sparklines declaratively using data attributes.

Line Sparkline

<span data-sparkline="line"
      data-values="5,10,8,15,12,18,14,20"
      data-width="100"
      data-height="30"></span>

Bar Sparkline

<span data-sparkline="bar"
      data-values="8,12,5,15,10,18,7,14"
      data-width="100"
      data-height="30"></span>

With Color Override

<span data-sparkline="line"
      data-values="20,18,15,12,10,8,5,3"
      data-color="negative"></span>

Programmatic Usage

// Line sparkline
Funky.Charts.line(container, [10, 15, 12, 18, 22, 19, 25], {
  width: 100,
  height: 40,
  color: 'positive'  // or 'negative', 'neutral', 'auto'
});

// Bar sparkline
Funky.Charts.bar(container, [5, 8, 3, 12, 7, 9, 4], {
  width: 100,
  height: 40,
  gap: 2
});

// Get trend direction from data
var trend = Funky.Charts.getTrend([1, 2, 3, 4, 5]);
// Returns: 'positive', 'negative', or 'neutral'

// Auto-initialize all data-sparkline elements
Funky.Charts.autoInit(container);
