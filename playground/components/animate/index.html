Scroll Animations

Elements animate when they enter the viewport.

Scroll-triggered animations use data-animate-trigger="in-view" attribute. The Animate module checks for elements entering the viewport and applies animation classes automatically.

<div data-animate-trigger="in-view" data-animate="fade-in-up">...</div>
